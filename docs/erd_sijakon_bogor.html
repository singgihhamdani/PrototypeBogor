Model struktur basis data terintegrasi yang mendukung 5 pilar pembinaan jasa konstruksi, pelaporan SIPJAKI Kementerian PUPR, pemetaan spasial 40 kecamatan, dan otomasi audit kepatuhan (Permen PUPR 1/2023).

SLA Query Response < 50 ms Optimalisasi Spatial GiST & Composite Index

🎯 Tujuan Desain Skema Basis Data

  • Integritas Multi-Tenant Terisolasi: Akun kontraktor (OPERATOR_BUJK) secara otomatis dibatasi hanya dapat mengakses rekaman data BUJK miliknya sendiri via kolom bujk_id.
  • Ketertelusuran Spasial (WebGIS): Menyimpan poligon batas administrasi 40 kecamatan (districts) dan titik lokasi proyek/kantor BUJK menggunakan tipe spasial PostGIS bawaan.
  • Otomasi Penilaian SIMAK 3 Pilar: Menyimpan kalkulasi pembobotan audit tertib usaha (40%), penyelenggaraan (35%), dan pemanfaatan (25%) sesuai Permen PUPR No. 1/2023.
  • Anti-Pemalsuan e-Sertifikat: Penerbitan sertifikat pelatihan TKK dilengkapi nomor registrasi unik dan hash token keamanan QR (qr_token).

📜 Dasar Regulasi & Standar Kepatuhan

UU No. 2 Tahun 2017 & PP No. 14 Tahun 2021

Kewenangan Pemerintah Daerah Kabupaten/Kota dalam pengawasan tertib usaha dan pembinaan tenaga kerja konstruksi.

Permen PUPR No. 1 Tahun 2023

Pedoman pengawasan penyelenggaraan jasa konstruksi dengan standar instrumen digital SIMAK.

Perda Kab. Bogor No. 2 Tahun 2020

Pemberdayaan dan optimalisasi pelaku jasa konstruksi lokal di 40 Kecamatan se-Kabupaten Bogor.

🛡️ Prinsip Integritas Referensial (Foreign Key Rules)

ON DELETE RESTRICT

Mencegah penghapusan BUJK atau Wilayah yang sudah memiliki riwayat proyek aktif atau rekaman audit kepatuhan.

ON DELETE CASCADE

Menghapus otomatis seluruh child entitas bawaan: SBU BUJK, riwayat kurva S mingguan, dan entri peserta pelatihan.

ON DELETE SET NULL

Mempertahankan data audit logs dan inspeksi jika pengguna dinas pembuat mutasi dinonaktifkan dari sistem.

📈 Logika Kurva S & Deteksi Keterlambatan Kritis

Kolom Terhitung (Generated Column):

Kolom deviation dihitung otomatis di level database tanpa logic tambahan di backend: deviation = actual_pct - plan_pct.

Peringatan Dini Keterlambatan Kritis (SCM):

Jika deviation < -10%, status proyek otomatis masuk ke level waspada (CRITICAL_DELAY).

Efisiensi Query Spasial PostGIS:

Indeks idx_bujk_projects_geom_location bertipe GiST memungkinkan filter radius 5 KM atau agregasi per kecamatan.

Optimasi & SLA • High Performance Engine

Spatial GiST, Composite Indexing & Security

Konfigurasi optimasi PostgreSQL untuk menjamin latensi query di bawah 50 milidetik saat melayani ribuan pengguna simultan dan kalkulasi geospasial berat.

⚡ 3 Pilar Indexing Strategis

1. Spatial GiST Indexes (PostGIS Engine): 
CREATE INDEX idx_districts_geom ON districts USING GIST (geom_boundary);
CREATE INDEX idx_bujk_projects_geom ON bujk_projects USING GIST (geom_location);
2. B-Tree Indexes untuk Filter Cepat & Relasi: 
CREATE INDEX idx_bujk_projects_filter ON bujk_projects (fiscal_year, budget_source);
CREATE INDEX idx_sbu_validity ON bujk_sbu (valid_until);
3. Full-Text Search GIN Index (Bahasa Indonesia): 
CREATE INDEX idx_regulations_fts ON regulations 
USING GIN (to_tsvector('indonesian', title || ' ' || number));
