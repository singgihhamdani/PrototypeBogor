Setiap pengguna hanya mengakses data dan fitur sesuai kewenangannya — menjaga independensi dan integritas audit.

6 Eksekutif Daerah Bupati, Sekda, Kadis Read-only dashboard eksekutif, WebGIS, KPI summary, unduh ringkasan laporan pimpinan
7 Peserta TKK & Publik Tenaga kerja, mahasiswa, warga Daftar pelatihan, repositori regulasi publik, scan QR Code validasi sertifikat

Isu Kunci Akuntabilitas & Tata Kelola Solusi Terintegrasi SIJAKON
"Apakah tumpang tindih dengan SIPJAKI kementerian?" Tidak. SIPJAKI pusat adalah sistem pelaporan nasional (hilir). SIJAKON adalah sistem kerja operasional daerah (hulu) yang mengotomasi pengumpulan data dan mempermudah pelaporan ke SIPJAKI.
"Bagaimana jika dinas non-PUPR lambat input data?" Tersedia Import Batch Excel (ekspor dari SiRUP/SPSE lalu unggah dalam hitungan detik), diperkuat SE Sekda tentang integrasi satu pintu pelaporan data konstruksi.
"Bagaimana jaminan keamanan data antar kontraktor?" Menerapkan Row-Level Security (RLS) dan RBAC 7 tingkat. Akun rekanan hanya dapat mengakses profil dan paket proyek perusahaannya sendiri.
"Kapan sistem siap dioperasikan secara penuh?" Desain UI/UX, alur proses audit SIMAK, dan skema basis data telah matang 100%. Peningkatan ke backend produksi ditargetkan rampung dalam 5 bulan sesuai roadmap.
