Isu 01 • Fragmentasi

Data Tersebar Lintas OPD

Data paket pekerjaan fisik terfragmentasi di DPUPR, Disdik, Dinkes, dan Disperkim tanpa adanya pangkalan data terpusat (single source of truth).

Isu 02 • Visibilitas

Deteksi Dini Deviasi Lambat

Realisasi fisik lapangan vs penyerapan keuangan SP2D seringkali baru diketahui terlambat menjelang tutup tahun anggaran, memicu risiko pekerjaan mangkrak.

Isu 03 • Regulasi

Mandat Pengawasan 3 Tertib

Kewajiban audit berkala Tertib Usaha, Tertib Penyelenggaraan, dan Tertib Pemanfaatan sesuai Permen PUPR No. 1/2023 membutuhkan instrumen penilaian terstandar.

Isu 04 • Ketenagakerjaan

Validitas Kompetensi TKK

Target tahunan sertifikasi 500 Tenaga Kerja Konstruksi membutuhkan pembuktian keabsahan kompetensi yang cepat dan dapat diverifikasi di lapangan via QR Code.

Arsitektur & Konsep Solusi

Arsitektur Hybrid Dual-Engine SIJAKON

Menyeimbangkan kebutuhan demonstrasi purwarupa yang interaktif dan aman bagi penguji (sandbox environment) dengan kesiapan integrasi penuh ke basis data cloud relasional.

Layer 1 • Antarmuka
Next.js 14 App Router
Aplikasi web responsif, render cepat di desktop pimpinan maupun smartphone pengawas lapangan.
Layer 2 • Hak Akses
RBAC 5 Peran Pengguna
Pemisahan wewenang mutlak antara Super Admin, Pengawas, Eksekutif, Rekanan BUJK, dan Peserta.
Layer 3 • Spasial
WebGIS Engine 40 Kecamatan
Visualisasi batas wilayah, sebaran 10 titik BUJK, dan progres paket konstruksi berbasis koordinat.
Layer 4 • Basis Data
Cloud Database PostgreSQL
Persistensi profil pengguna, audit trail log, dan penyimpanan data cloud yang terenkripsi.

Tur Fungsional • Modul 03

Katalog Paket Proyek & Universal Batch Import

Transparansi data administrasi kontrak (SPMK, PHO, PPK) serta kemudahan migrasi ratusan data paket pekerjaan tanpa risiko kesalahan penamaan kolom.

Fitur 01 • Transparansi Kontrak

Detail Teknis Proyek (Contoh: P001)

Menampilkan paket Peningkatan Jalan Ruas Sukaraja - Katulampa: nomor SPMK, nilai kontrak, nama PPK dinas, kontraktor pelaksana, konsultan pengawas, dan riwayat addendum.

Universal Header Matching & Fallback

Mesin impor mengenali multi-alias kolom (misal: "Nama Paket", "Paket Pekerjaan", "Uraian Kegiatan") dan menerapkan fallback otomatis sehingga file Excel dari OPD mana pun tidak akan error/tertolak.

Tur Fungsional • Modul 05

Pelatihan TKK & Penerbitan E-Sertifikat QR Code

Pencatatan akuntabel program pembinaan tenaga kerja terfasilitasi APBD, kurikulum 32 JP, penilaian asesor BNSP, dan sertifikasi digital terverifikasi.

Tahap 01 • Pembekalan

Kurikulum 32 JP Terstruktur

Tahap 02 • Asesmen

Hasil Uji Asesor BNSP

Penetapan status Kompeten (K) pada 5 unit standar kompetensi SKKNI berbasis Berita Acara Asesmen LSP Konstruksi terlisensi.

QR Code Verifikasi Lapangan

QR Code dinamis pada e-Sertifikat langsung menampilkan status validitas sertifikat saat dipindai kamera smartphone pengawas lapangan.

Mekanisme Verifikasi Data Pra-Cetak: Demi mencegah pergantian identitas / joki sertifikasi, data NIK (16 digit) dan jenjang kompetensi dikunci permanen (read-only). Permohonan koreksi salah ketik nama atau gelar wajib melampirkan foto e-KTP untuk disetujui 1-klik oleh admin dinas.

Kebijakan Integrasi Nasional

Integrasi Data Pelaporan SIPJAKI Kementerian PUPR

Memastikan pemenuhan kewajiban pelaporan sub-urusan jasa konstruksi daerah tanpa menimbulkan ketergantungan teknis API eksternal yang kompleks.

Prinsip Integrasi Kementerian: Portal SIPJAKI Kementerian PUPR beroperasi sebagai sistem pelaporan nasional di hilir. SIJAKON Kabupaten Bogor dirancang sebagai sistem operasional kerja di hulu. Mekanisme integrasi resmi dilakukan melalui Ekspor Berkas Data Terstruktur (.xlsx multi-sheet) yang telah terstandarisasi 100% dengan formulir SIPJAKI pusat.
Strategi 01 • Hulu ke Hilir

Tidak Tumpang Tindih

SIJAKON mengumpulkan data harian proyek dari seluruh OPD teknis Kabupaten Bogor, memverifikasinya, lalu menyiapkannya dalam format pelaporan nasional.

Strategi 02 • Format Standar

Ekspor 1-Klik Multi-Sheet

Data paket pekerjaan, BUJK, hasil audit SIMAK, dan peserta TKK dapat diekspor menjadi dokumen Excel yang siap diunggah berkala oleh operator dinas.

Strategi 03 • Kemandirian Sistem

Bebas Kendala Koneksi Pusat

Sistem operasional dinas tetap berjalan lancar tanpa terganggu jika sewaktu-waktu server pusat kementerian sedang mengalami pemeliharaan (maintenance).

Kesiapan Engineering & Arsitektur

Kesiapan Purwarupa vs Target Fase Produksi

Transparansi rekayasa perangkat lunak yang memetakan kapabilitas sistem saat ini dengan rencana deployment produksi di infrastruktur Diskominfo.

Komponen Arsitektur Status Purwarupa Saat Ini (Prototype) Target Fase Produksi Penuh (Go-Live)
Penyimpanan Basis Data Hybrid Dual-Engine Terhubung aktif ke Cloud Database (PostgreSQL) untuk data profil/user, didukung sandbox peramban untuk demo. Pangkalan data terpusat PostgreSQL 16 Enterprise dengan ekstensi spasial PostGIS di Server Data Center Diskominfo.
Autentikasi & Keamanan Autentikasi cloud berbasis JWT, proteksi RBAC 5 role, dan selector cepat akun simulasi demo. Integrasi penuh dengan Single Sign-On (SSO) Satu Data Kab. Bogor (OAuth2/SAML) & verifikasi 2-faktor (2FA).
Pemetaan Spasial (GIS) Peta vektor interaktif dengan layer GeoJSON spasial batas 40 kecamatan dan 10 titik BUJK. Penyajian layer spasial resmi yang terintegrasi dengan data geospasial RTRW Bappedalitbang & ATR/BPN.
Integrasi SIPJAKI Pusat Ekspor berkas format Excel (.xlsx multi-sheet) terstandarisasi dengan formulir Kementerian PUPR. Optimalisasi berkas data terstruktur (.xlsx/.csv) siap unggah berkala oleh operator dinas ke portal kementerian.
Penyimpanan Berkas Digital Penyimpanan berkas cloud untuk modul pelatihan, bukti e-KTP, dan dokumen kontrak uji coba. Penyimpanan objek cloud (Object Storage) terpusat dengan enkripsi dokumen kontrak dan BAST.
